# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Bare-metal firmware for the **NUCLEO-L552ZE-Q** development board (STM32L552ZET6Q — Cortex-M33, 512 KB Flash, 192 KB RAM). Generated and partially managed by **STM32CubeMX 6.17.0**. IDE is CLion.

## Build Commands

```bash
# Configure (first time or after CMakeLists changes)
cmake --preset Debug

# Build
cmake --build --preset Debug

# Output binary
build/Debug/debug_l5.elf
```

For Release:
```bash
cmake --preset Release && cmake --build --preset Release
```

The build uses **Ninja** as the generator and outputs a `.map` file alongside the `.elf`.

## Toolchains

Two toolchain files are provided:

| File | Compiler | Notes |
|------|----------|-------|
| `cmake/gcc-arm-none-eabi.cmake` | `arm-none-eabi-gcc` | **Default** (referenced in `CMakePresets.json`) |
| `cmake/starm-clang.cmake` | `starm-clang` | Alternative; supports STARM_HYBRID, STARM_NEWLIB, STARM_PICOLIBC (default: PICOLIBC) |

To switch toolchain, change the `toolchainFile` in `CMakePresets.json`.

Target flags: `-mcpu=cortex-m33 -mfpu=fpv5-sp-d16 -mfloat-abi=hard`

## Flashing & Debugging

Flash via ST-LINK (SWD on PA13/PA14). The CLion debug configuration (`/.idea/debugServers/ST_LINK.xml`) is pre-configured. From the command line:

```bash
# Convert ELF to binary
arm-none-eabi-objcopy -O binary build/Debug/debug_l5.elf build/Debug/debug_l5.bin

# Flash with st-flash
st-flash write build/Debug/debug_l5.bin 0x8000000

# Or use OpenOCD
openocd -f interface/stlink.cfg -f target/stm32l5x.cfg -c "program build/Debug/debug_l5.elf verify reset exit"
```

## Architecture

### Code Organization

```
Core/Src/        — Application sources (user-editable)
Core/Inc/        — Application headers
Drivers/         — STM32 HAL + CMSIS (do not edit; regenerated by CubeMX)
cmake/stm32cubemx/CMakeLists.txt  — CubeMX-generated source/include lists
startup_stm32l552xx.s             — Reset handler and vector table
STM32L552xE_FLASH.ld              — Flash linker script (512KB Flash, 192KB RAM)
STM32L552xx_RAM.ld                — RAM execution linker script
debug_l5.ioc                      — STM32CubeMX project file
```

### STM32CubeMX Code Generation

CubeMX regenerates `Core/Src/`, `Core/Inc/`, and `cmake/stm32cubemx/CMakeLists.txt` when `.ioc` settings change. **User code must live between the guard markers** or it will be overwritten:

```c
/* USER CODE BEGIN X */
// safe to edit here
/* USER CODE END X */
```

### HAL Peripheral Initialization

Peripheral init functions follow the `MX_<Peripheral>_Init()` pattern and are called from `main()`. Currently configured: GPIO (LEDs LD1/LD2/LD3, LPUART1 pins), ICACHE, RCC (HSI → PLL → 110 MHz SYSCLK), SysTick.

### Clock Configuration

HSI (16 MHz) → PLL (PLLM=4, PLLN=55, PLLR=2) → 110 MHz SYSCLK. Voltage scale 0 required at this frequency. Flash latency: 5 wait states.

### Error Handling

`Error_Handler()` disables interrupts and loops forever. Add debug output (UART, semihosting, ITM) inside the `USER CODE BEGIN Error_Handler_Debug` section if needed.
